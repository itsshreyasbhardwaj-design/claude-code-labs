# Roadmap

The full roadmap lives at the top level of the repo: **[ROADMAP.md](../ROADMAP.md)**.

Short version:

- **Platform features (planned, not built)**: Drift Radar (doc-vs-code
  contradiction detection), an AI Provenance Ledger (git-blame-style trust
  layer for AI-driven commits), a Project Health Score (trended composite
  dashboard), and an Onboarding Simulator (zero-context agent QA for docs).
- **Near-term technical items**: an opt-in `--live` MCP introspection mode to
  measure real tool-schema token cost, and a pnpm-workspaces monorepo
  migration once a second flagship feature enters active development.

See [ROADMAP.md](../ROADMAP.md) for the full detail on each item.
